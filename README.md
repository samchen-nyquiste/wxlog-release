# WXLog 下载

微信聊天记录导出与分析工具（仅限导出你自己账号的本地记录）。

## 下载（无需登录）

**最新版 Windows：** 到 [Releases](../../releases/latest) 页，下载 `WXLog.exe`。

直链：`https://github.com/samchen-nyquiste/wxlog-release/releases/latest/download/WXLog.exe`

## 使用
1. 打开并登录电脑版微信（确保聊天记录已从手机迁移到电脑）。
2. 双击 `WXLog.exe`，浏览器会自动打开，点「一键开始」。
3. 首次运行若杀毒/SmartScreen 拦截，选择"仍要运行"（它需要读取微信内存来解密，是正常行为）。

数据全程只在你自己电脑本地处理，不上传。
